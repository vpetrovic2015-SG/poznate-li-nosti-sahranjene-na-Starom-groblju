# Старо гробље — Пожаревац (нови обједињени репозиторијум)

Ова верзија обједињује договорени црно-златни дизајн, каталог личности, биографије, оптимизоване портрете, фотографије гробних места, QR кодове, интерактивну мапу, навигационе руте и 3D приказе за профиле за које је модел доступан.

## Постављање на GitHub Pages
1. Направите резервну копију постојећег репозиторијума.
2. Распакујте ZIP на рачунару.
3. Отпремите **садржај** ове фасцикле у корен репозиторијума (не саму фасциклу као поддиректоријум).
4. Проверите да су `index.html`, `styles.css`, `app.js`, `data/` и `assets/` на истом нивоу.
5. Commit changes и сачекајте GitHub Pages изградњу.
6. Отворите сајт и урадите hard refresh (Ctrl+F5). 

## Функције
- Претрага која ради са ћириличним и латиничним уносом.
- Избор писма ћирилица/латиница.
- Лични профили са картицама за биографију, фотографије, гробно место, 3D и QR.
- Leaflet/OpenStreetMap мапа за особе са координатама у `data/licnosti.json`.
- Google Maps руте до гробља и до координата појединачних гробних места.
- 3D модели су приказани само у профилима којима су додељени у `model_3d`.
